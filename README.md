## 🚀 Getting Started

To run the website locally:

### 1. Clone the repository

```bash
git clone https://github.com/sujitha7s/Magizhvagam.git
```

### 2. Navigate to the project

```bash
cd Magizhvagam
```

### 3. Open the website

Open `index.html` in any modern web browser.

You can also use **VS Code + Live Server** for local development.

---

## 🌍 Deployment

The website can be deployed using **GitHub Pages**.

The repository contains the main website files in the root directory, making it suitable for static website hosting.

### GitHub Pages Setup

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
5. Click **Save**.
6. GitHub will generate the public website URL.
